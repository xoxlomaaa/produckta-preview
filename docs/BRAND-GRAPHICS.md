# Фирменный росчерк · правила Produckta

По указанию пользователя от 12.11.2026 **крупный росчерк — исходное решение для всех новых цветных блоков**. Не уменьшать его до маленького украшения в углу.

- Использовать настоящий `assets/illustrations/brand-ramp-mask.svg`. Контур не перерисовывать и не растягивать по осям.
- Выбирать масштаб по видимой форме в конкретном контейнере: широкий изгиб и толстая линия должны ощущаться частью фона. Само большое значение CSS-ширины ещё не гарантирует нужный эффект.
- В кадре должна читаться петля или характерный возврат линии. Две случайные параллельные полосы после обрезки — не готовая композиция.
- Для нового блока подбирать собственные положение, угол и обрезку. Не копировать координаты предыдущей плашки.
- В короткой плашке сначала найти положение самой петли; если места мало, дать контейнеру немного высоты. Не скрывать весь изгиб за краем ради сохранения узкой полосы.
- Цвет брать из палитры блока, контраст фона делать мягче текста. Росчерк не должен ухудшать чтение, перекрывать управление или создавать горизонтальную прокрутку.
- На белом фоне не добавлять декоративные линии автоматически: правило относится к фирменной графике в цветных контейнерах, а не к каждому пустому месту.

## Текущие изменения

- Исследование рынка: крупная петля 160rem, размещённая внизу слева и повёрнутая на −12°.
- Мерч: контейнер минимум 21rem, петля в правой части с поворотом −14°. Видна сама форма вместо двух диагональных полос.
- Ранее согласованные крупные фоны Hero, отраслей, команды, отзывов и заявки сохраняются.

Владельцы — стили соответствующего компонента. Точечные снимки 1920/1024/390 и проверка затронутых блоков: `output/qa/composition-polish/`, скрипт `output/implementation/check-composition-polish.cjs`.
