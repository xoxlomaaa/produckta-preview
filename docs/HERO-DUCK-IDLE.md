# Короткое покачивание утки Hero

12.11.2026. По запросу пользователя после общего входа Hero утка со скейтом продолжает изредка двигаться. Горка, стартовая точка, текст и опыт не качаются.

## Реализация

- `src/js/hero-idle.js` владеет наблюдателем видимости, таймером и одной конечной WAAPI-анимацией. `page-motion.js` даёт сигнал start после завершения входа `.hero-art` либо его досрочного завершения пользователем. Destroy освобождает observer, отменяет таймер/движение; listeners принадлежат общему AbortSignal.
- Первая анимация через 5000ms после входа, далее начало раз в 5000ms: 1000ms движения и около 4000ms покоя. Это не бесконечная CSS-анимация; во время пауз эффект и transform не удерживаются.
- Угол 0 → −1.1° → +.66° → −.242° → 0; подъём максимум 1px. На телефоне угол −.8° / +.48° / −.176°, подъём .6px. Параметры и порог 48rem принадлежат `src/styles/page-motion.css`.
- На каждой части жеста easing `cubic-bezier(.45,0,.55,1)` для мягкой смены направления. Поворот вокруг области скейта, `transform-origin: 71% 28%` полного SVG-слоя.
- Скрытая вкладка либо выход иллюстрации из viewport отменяют движение и таймер. Возврат запускает новую паузу 5s; пропущенные жесты не догоняются. Resize также отменяет текущий жест и начинает паузу заново.
- Reduced motion отключает эффект вместе с остальной motion-системой. У входа Hero по-прежнему общий родитель/таймлайн; отдельной входной траектории утки нет.

## Вектор и адаптация

Используются точные производные оригинального `duck-ramp.svg`: `hero-ramp-layer.svg` (горка и точка), `hero-duck-layer.svg` (утка, скейт и штрихи). Контуры/цвета не перерисовывались. Размеры и координаты обоих img совпадают на каждом режиме; общий вход трансформирует только `.hero-art`.

## Точечная проверка

Chrome, localhost 4330. Сценарий — `output/implementation/check-hero-duck-idle.cjs`, отчёт/снимки — `output/qa/hero-duck-idle/`.

- 390/1920px: одинаковые рамки двух слоёв, нет переполнения. Движется только утка; у горки и родительской сцены в этот момент нет активных эффектов.
- Фактический первый старт после входа: 5002.6/5000.7ms; период между стартами: 5007.8/5009.6ms. Длительность жеста 1000ms.
- Выход из Hero отменил жест; за следующие 5.1s новых жестов не было. Включение reduced motion остановило эффект.
- 320px с reduced motion: утка видима и статична, переполнения нет.
- Canvas-сравнение совмещённых слоёв и оригинала: 0 различающихся каналов.
- Десять защищённых файлов, включая прокрутку, интерактивные сцены и исходный SVG, не изменились. Ошибок JS нет. Сборка, ссылки/бюджеты и существующий контроль палитры прошли.

Физический телефон, Lighthouse и полная регрессия витрины не запускались. Поведение скрытой вкладки предусмотрено обработчиком visibilitychange; отдельная проверка фоновой вкладки в этот прогон не входила.
