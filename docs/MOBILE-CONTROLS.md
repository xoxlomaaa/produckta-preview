# Мобильные кнопки и политика

Уточнение 12.11.2026: политика в согласии теперь inline-ссылка с постоянным подчёркиванием в тексте предложения, без рамки, подложки и стрелки. Полное accessible name checkbox формируется через aria-labelledby. Ссылка открывает прежний dialog, не меняет согласие/hash; Escape возвращает фокус. На телефоне текст 13–14px. Проверено 320/375/390/768/1920px, переполнения нет; кнопка подвала сохранена. Сценарий/снимки — `output/implementation/check-inline-policy.cjs`, `output/qa/inline-policy/`. 12.11.2026. Правка по запросу пользователя; применены adapt и better-typography. Только src/styles/home.css, внутри @media (width < 48rem). Desktop-правила и DOM не менялись.

Причина тесноты: кнопка политики делила узкую текстовую колонку с пояснением согласия рядом с чекбоксом. Теперь .request-consent — grid из колонки чекбокса и текста; техническая div-обёртка display:contents, кнопка занимает следующую строку на обе колонки. Ассоциация label/checkbox, порядок фокуса и обработчик политики сохранены.

Внутренние поля плашки 12px, зазор до кнопки 14px. Кнопка высотой минимум 48px, Manrope 14px, текст слева, стрелка справа, горизонтальные поля 8px и минимальный зазор 8px. На 320px доступно 176px, и «Открыть политику» помещается в одну строку без уменьшения шрифта. На 375/390/430px ширина 231/246/283px соответственно.

Кнопка политики в подвале на телефоне занимает доступную ширину, высота минимум 48px, при необходимости переносится целыми словами; стрелка не сжимается. Основные CTA, меню, Hero и интерфейсы внутри демонстраций сохранены: по этой проверке дополнительного вмешательства они не требовали.
