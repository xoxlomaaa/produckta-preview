# Мобильная проверка и облегчение анимаций

12.11.2026. Проверена именно мобильная прокрутка контентной части. Основной Hero, покачивание утки, колесо/интерактивная витрина и desktop-профиль не перенастраивались.

## Найдено и исправлено

| Приоритет | Компонент/состояние | Что было не так | Правка | Проверка |
|---|---|---|---|---|
| P1 | Изменение высоты окна | Любой resize отменял все эффекты. В пробе 7 появлений оборвались примерно через 140ms | Компактный режим игнорирует изменение только высоты; ширина/ориентация обрабатываются штатно | После изменения высоты отменённых эффектов 0 |
| P1 | Начало свайпа по карточке | Любой pointerdown завершал её вход: до касания 1 анимация, после 0 | Touch по статичному контенту не считается действием. Кнопки, ссылки, поля, label/summary и клавиатурный фокус сохраняют немедленный отклик | Статичное касание оставляет эффект активным, native touch двигает страницу |
| P2 | Запоздалое появление | Длительность 900/1100ms, scatter до 140ms, фиксированные 100ms у макетов Ideas | Короче движение и паузы; мобильный trigger ближе к краю viewport | Активны профиль 650/800ms и scatter до 80ms |
| P2 | Фото/крупные иллюстрации | Масштаб .96 → 1 и ход 54px избыточны на коротком экране | Масштаб постоянный 1, ход 32px; filled-frame сохраняется | Нулевая разница границ фото и рамки |

## Компактный профиль

Владелец — `src/styles/page-motion.css`; JavaScript читает custom properties, не дублирует числовой breakpoint.

| Параметр | Телефон раньше | Телефон сейчас | Desktop сохранён |
|---|---|---|---|
| Текст: ход / длительность | 32px / 900ms | 20px / 650ms | 52px / 1050ms |
| Визуал: ход / длительность | 54px / 1100ms | 32px / 800ms | 88px / 1300ms |
| Масштаб визуала | .96 → 1 | 1 | .96 → 1 |
| Задержка описания | 120ms | 60ms | 170ms |
| Перемешанные задержки | 0–140ms | 0–80ms | 0–220ms |
| Базовая задержка макета Ideas | 100ms | 0ms | 100ms |
| Observer: threshold / margin | .12 / 0 0 -10% 0 | .08 / 0px | .12 / 0 0 -10% 0 |

Порядок соседей остаётся перемешанным. Hero и его idle-жест используют прежние собственные параметры.

Компактный режим — базовый до 48rem, а также короткие touch-окна шириной 48–64rem и высотой <34rem. Desktop от 64rem, окна с мышью от 48rem и высокие планшетные окна от 48rem сохраняют предыдущий профиль. Это оставляет широкие desktop-окна прежними и облегчает телефон в landscape.

При реальном переходе между профилями основной observer пересоздаётся для ещё не показанных целей; footer сохраняет свой edge-observer. Старые callback от отсоединённого observer игнорируются. Resize не добавляет обработчиков и не переигрывает уже показанный контент.

## Границы и результаты проверки

Chrome с `isMobile`, `hasTouch`, DPR 2. Скрипты: `output/implementation/check-mobile-motion.cjs`, `check-mobile-motion-orientation.cjs`. Отчёты/снимки — `output/qa/mobile-motion/`; baseline — `before.json`.

- 320×740, 375×812, 390×844, 430×932: обычный и быстрый свайп через CDP `Input.dispatchTouchEvent`, native scroll 158–162px в контрольном жесте. Wheel не использовался.
- Для 390px включено CPU ×4. Наблюдения requestAnimationFrame во время короткого сценария: p95 14ms, один интервал 76.5ms из 179. На остальных профилях p95 7–7.5ms, до одного интервала >50ms. Частота host-renderer около 144Hz; это не измерение FPS реального телефона или GPU слабого устройства. Гарантия отсутствия всех рывков не заявляется.
- Изменение высоты −80px не отменило активные входы. Touch статичного пункта сохранил его анимацию. Фото по всем четырём краям совпало с заполненной рамкой; img не получил собственного transform.
- Проверены фокус поля, открытие/закрытие меню касанием, reduced motion, отсутствие переполнения. Ошибок JS нет.
- 844×390 после разворота использует компактный профиль; следующие цели продолжают появляться. После обратного разворота виден последний элемент подвала.
- 1920×1080 и короткое mouse-окно 1920×500: прежние desktop-длительности, ходы, масштаб, задержки и trigger. Мышь по карточке по-прежнему завершает её вход.
- Защищённые исходники прокрутки и витрины не изменились. Build, ссылки/бюджеты и палитра прошли.

Физический Android/iPhone и Safari iOS недоступны в этом прогоне. Lighthouse и общая регрессия интерактивной витрины не запускались.
