## Подготовка и отображение

- Только SVG с векторными контурами. Нет встроенных растров, текста с зависимостью от шрифта, скриптов или ссылок на внешние ресурсы. Буквы и контуры не генерировались и не перерисовывались.
- Цветные области сведены к фирменному `#454A5D`, белые прорези сохранены. Убраны только пустые внешние поля, пропорции сохранены. Корректность извлечения PDF проверена по растровым изображениям оригиналов и листу `vector-proof.png` с полным контрастом.
- В CSS единая непрозрачность `.28` на белом фоне даёт тихий светло-серый ряд. У всех картинок `object-fit: contain`; для каждого видимого знака задана собственная оптическая ширина.
- Сетка 2×3 на телефоне, 3×2 с 48rem и 6×1 с 64rem. Подпись и общее размещение секции сохранены. Логотипы не являются кнопками и не создают лишних остановок Tab.
- `alt` содержит имя компании; заданы размеры, `loading="lazy"` и `decoding="async"`. Внешних CDN, API, шрифтов или удалённых изображений нет.
- `tools/build.mjs` копирует `assets/partners/` в `dist/assets/partners/`; исходные PDF, страницы и инструменты подготовки не попадают в сборку. Контроль палитры теперь включает эту папку.

Владельцы: разметка — `src/index.html`, CSS — `.partners`/`.partner-list`/`.partner-logo` в `src/styles/home.css`. Сборка остаётся воспроизводимой на Node.js без установки зависимостей и обращения к интернету. Служебный конвертер `output/implementation/prepare-partner-logos.py` использует PyMuPDF 1.26.7 только для подготовки ассетов; это не runtime-зависимость сайта.

## Проверка

`node output/implementation/check-partner-logos.cjs` → `output/qa/partner-logos/check.json`, снимки `partners-{1920,768,390}.png`. Chrome: все восемь знаков декодированы, доступны локально с HTTP 200 и SVG MIME; внешних запросов нет при заблокированном HTTPS, картинки помещаются в ячейки, сетка 4/4/2, переполнения и ошибок JS нет. Просмотрены десктопный и мобильный снимки. Сборка, палитра и статические ссылки/бюджеты пройдены. Общая регрессия и Lighthouse не запускались.

Условные компании/логотипы внутри самих шести отзывов остаются прежними демонстрационными заготовками. Они не заменены названиями из нового ряда компаний и не превращены в вымышленные рекомендации от этих брендов.

Caparol уточнён: удалены только 18 контуров слогана THE POWER OF SURFACE., viewBox обрезан по слону/названию, размер увеличен. Исходный SVG до удаления сохранён в output/checkpoints/before-graphics-locker-wolf-2026-11-12/caparol.svg. Контуры самого знака и слова CAPAROL не менялись.

Текущий оптический баланс: Caparol 60x56px, Архитектоника 128px шириной; с 64rem flex space-between с равными промежутками между краями знаков. Ранее записанные 6×1 обозначают один ряд из шести, а не текущую сетку CSS grid. Проверки — FAQ-PARTNER-BALANCE.md.
