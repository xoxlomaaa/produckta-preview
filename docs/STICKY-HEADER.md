# Закреплённая шапка

Шапка остаётся сверху во всех разделах на desktop и телефоне. Белая непрозрачная поверхность и тонкая тень после первых 8px прокрутки; высота при скролле не меняется. Размытие и постоянные анимации не используются.

- `src/index.html`: общий sticky-контейнер `.site-header-wrap`; мобильный dialog остаётся отдельным дочерним элементом body.
- `src/styles/home.css`: положение, safe-area, фон/тень, CSS fallback высоты, scroll-padding. Существующий отступ якорей 24px сохраняется.
- `src/js/sticky-header.js`: измерение высоты через ResizeObserver, CSS-переменная и событие `produckta:header-resize`; пассивный scroll переключает только класс тени. Повторная инициализация безопасна; lifecycle учитывает BFCache.
- `src/showcase/architecture-preview.js`: размер и центрирование превью учитывают пространство под шапкой. Передача колеса между iframe и страницей сохранена.
- `src/showcase/locker/src/js/render-story/hero.js`: повторное измерение при изменении высоты шапки; настройки динамики, кадры и общее колесо не изменены.
