## Архитектура и ресурсы

- Статический HTML, основной CSS и изолированные стили раздела возможностей. ES-entry points — `src/js/home.js` и `src/showcase/showcase.js`, один общий контроллер прокрутки. Сборка на Node.js 24 без установки пакетов: копирует `src/`, публичные ресурсы и собирает секцию из `templates/`. Снимки необходимых ресурсов других проектов сохранены локально в `assets/showcase/`; сборка не обращается к донорам и папке эксперимента. Выход — `dist/`; совместимый второй preview — `experiments/capabilities/dist/`. Очищать разрешено только эти два явно проверенных пути. Мастера, макеты, отчёты и история не публикуются.
- Палитра брендбука — зелёно-бирюзовый #78A5A2, коралловый #CD5A57, охра #E0AF6A, серо-синий #454A5D, сливовый #4C3F53 и нейтральный белый. Самостоятельные тёмные заменители не используются: мелкий текст — фирменный сливовый/серо-синий, светлые подложки — смеси палитры с белым. Правила — `BRAND-PALETTE.md`.
- Локальный Manrope 5.3.0, variable 200–800, Cyrillic и Latin, OFL. Оба подмножества используются на первом экране и предварительно загружаются. Предзагрузка добавлена после измеренного сдвига при смене шрифта.
- Три SVG утки извлечены из векторного брендбука, контуры сохранены, цвета приведены к роли рисунка. Одноразовый скрипт извлечения — output/implementation/extract-brand.py, для его повторного запуска нужны Python и pypdf.
- Архитектурное изображение — сгенерированный материал для концепта, мастер assets/source/architecture-concept.png. Производные WebP 480 и 800 px подготовлены Sharp, quality 80, effort 6. Высокий приоритет на первом экране получает единая SVG-композиция трамплина и утки. Ниже экрана используется srcset/sizes и lazy loading.
- В разделе «Идеи — в дело» показаны визуальные примеры решений; по запросу пользователя плашки «Концепт Producta» убраны. В команде размещены одобренные портреты Ксении и Александра и временная студийная иллюстрация волка вместо фото Кирилла. По запросу пользователя созданы шесть явно обозначенных демо-отзывов с вымышленными именами, компаниями и условными SVG-логотипами. Это заготовки для композиции, не подтверждённые рекомендации клиентов; перед публикацией заменить реальными материалами.
- Сценарий и промпт иллюстрации архитектуры — output/implementation/architecture-concept.prompt.txt.

## Сетка и поведение

- Телефонный motion-профиль: текст 650ms/20px, визуал 800ms/32px без изменения масштаба, scatter до 80ms. Height-only resize и касание статичного контента не прерывают появления. Desktop-параметры сохраняются. Контракт и проверка native touch — MOBILE-MOTION.md.

- Для всей контентной части действует общий ритм появлений по образцу «Идеи — в дело». Заголовки/описания и самостоятельные группы входят по своей видимости; процесс без задержек по номерам. В кейсах анимируются внешние текстовые блоки и статичная экспертиза; интерактивные оболочки сохраняют свои механизмы. Контракт — CONTENT-MOTION.md.
- Соседи в группах входят в перемешанном порядке с задержками до 220/140ms. Фотографии команды анимируются вместе с рамками, img всегда заполняет их целиком; положение и контент в финале сохраняются. Hero использует прежнюю общую последовательность.

- FAQ `#faq` расположен после отзывов/логотипов перед заявкой. Восемь нативных `details/summary`, первый открыт, общий `name` группирует ответы. Стили в `src/styles/faq.css`, контент в `templates/sections/faq.html`; новых обработчиков JS нет. Контракт — `FAQ.md`.
- Переключатели FAQ — белые круги с серо-синей обводкой/стрелкой, при наведении красные с белой стрелкой; утка с клюшкой зеркально развёрнута и увеличена на 20%. Процесс оформлен общим сливовым контейнером как отрасли с крупным росчерком, белой уткой и текстом; этапы открытые, номера белые на бирюзовых кругах, прежняя сетка 2×2 сохранена. Команда — светлая бирюзовая подложка с тёмными подписями. В мерче текст под заголовком, прежняя композиция товаров справа. Реализация — `PROCESS-TEAM-MERCH.md`. Для новых цветных блоков крупный читаемый росчерк обязателен по брифу — `BRAND-GRAPHICS.md`.

- Раздел «Вот что мы можем.» включён в основную главную после `#process` перед `#about`. Сохранены исходные интервалы; после четырёх демонстраций добавлен пункт 05 с экспертизой команды из презентации: исследование рынка, партнёрские программы, внутренние коммуникации, полный цикл мерча. Источники — `EXPERTISE-CASES.md`. Локальное preview `http://127.0.0.1:4330/`, проверка корня/процесса — `/__frontend-health`. Источники и владельцы — `../PROJECT-MAP.md`.
- Темп чемодана на обычном колесе: число шагов каждого интервала умножено на 1.15; положение сцены, камеры, кадры и общая инерция страницы не менялись. Исходная анимация выполняется локальной адаптацией `src/showcase/locker/src/js/render-story/hero.js`, с ограничением догоняющего скачка до 3 кадров за paint. Touch остаётся нативным.

- Mobile-first. Слои CSS — base, layout, components, motion. Контейнер до 1200 px, поля clamp(20px, 5vw, 80px).
- С 32rem отрасли и логотипы расширяются до двух и трёх колонок. С 40rem услуги, этапы и отзывы — в две колонки. С 48rem концепты и отрасли — в три колонки, портреты команды — в три. С 64rem появляются desktop-навигация, широкая композиция hero, утка справа от этапов и две колонки заявки. Четыре направления услуг включаются с 75rem.
- На телефоне услуги — открытые текстовые направления, этапы и примеры решений — по одному в строке; утка процесса стоит под этапами. Единственный DOM и единственная форма во всех размерах.
- Мобильное меню — выезжающий справа нативный dialog, 320ms transform/opacity, без движения в reduced motion. Escape, крестик и ссылки закрывают его; нативный фокус остаётся внутри панели, фон блокируется. При переходе к desktop ResizeObserver закрывает меню и переносит фокус на логотип. Порогом владеет CSS. Без JS — основные ссылки noscript. Контракт — `MOBILE-HERO-MENU.md`.
- Кнопки обсуждения проекта ведут якорем к открытой форме в финальном блоке. Услуги — независимые checkbox, бюджет — radio. Обязательны задача, имя, телефон и согласие. Email и дополнительный вопрос необязательны. Политика открывается в нативном dialog с Escape и возвратом фокуса. Без JS отправка заблокирована, с JS работает локальная проверка без передачи данных. Контракт — request-form.md.
- Входы Hero, «Идеи — в дело» и «Как мы работаем»: transform/opacity, один раз, уменьшенная амплитуда/длительность на телефоне. Hero — общая временная шкала шапки, фона, цельного заголовка, описания, CTA, сцены и опыта. Трамплин, точка, скейт и утка входят вместе в исходной композиции. После входа утка со скейтом качается 1s раз в 5s; вне экрана/скрытой вкладки эффект приостанавливается. Фокус или нажатие сразу завершают вход Hero. В reduced motion всё статично. Контракты — PAGE-MOTION-PILOT.md, HERO-DUCK-IDLE.md; интерактивная витрина и её прокрутка управляются прежними модулями.

## Проверки и ограничения

- Команда npm.cmd run verify проверяет сборку, синтаксис, ID, якоря, файлы, noindex и бюджеты. Gzip фактически — HTML 4,8 КиБ, CSS 5,9 КиБ, JS 0,7 КиБ при лимитах 25/35/30 КиБ. Основная иллюстрация первого экрана с фото — 78,7 КиБ без сжатия, лимит 130 КиБ.
- Playwright / установленный Chrome проверили ширины 320, 375, 390, 640, 767, 768, 960, 1023, 1024, 1440 и 1920 px. Проверены переполнение и заголовки, меню с клавиатуры, смена режима с фокусом внутри меню, якоря, валидация формы, сохранение ввода при resize, открытая форма на пяти ширинах, reduced motion и сценарий без JS.
- Скриншоты и отчёты — output/playwright/. Скрипты проверки используют локально доступные инструменты машины, не входят в сборку и не являются runtime-зависимостями.
- Локальный preview намеренно имеет noindex. Canonical, sitemap, политика конфиденциальности, реальная доставка заявки и проверка хостинга определяются перед публикацией. Физические телефоны, Safari и Firefox пока не проверены.
